# Project Skills

This project's Claude Code skills are installed under `.claude/skills/`.

- `social` — local Instagram/Facebook organic social planning and measurement.
- `content-strategy` — content pillars, prioritization, and repurposing.
- `marketing-plan` — cross-channel marketing planning; use only when the scope is broader than a social calendar.

These project-local skills are tailored copies of upstream skill guidance and include local-restaurant safeguards (no invented menu details, prices, promotions, or customer claims). Upstream sources are linked in each skill's frontmatter.
